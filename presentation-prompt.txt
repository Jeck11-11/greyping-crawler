ABOUT GREYPING

GreyPing is a cloud-based platform that scans any website or domain and produces a comprehensive security report in under 2 minutes. It shows business owners their external attack surface — everything a hacker can see from the outside — and translates technical findings into business risk with euro/dollar figures, compliance scores, and plain-English recommendations.

Think of it as a full security health check for your online presence, delivered instantly.

---

TARGET AUDIENCE

- SMB owners (10-250 employees) who know security matters but don't have a dedicated security team
- IT managers at SMBs who need to demonstrate due diligence to leadership or insurers
- Companies preparing for Cyber Essentials, ISO 27001, or regulatory audits
- Businesses who've been breached or had a near-miss and want visibility

THREE SCAN MODES

1. FULL SCAN (30-120 seconds)
   - Crawls up to 50 pages with optional JavaScript rendering
   - Tests 57 sensitive paths (.env, .git, /admin, wp-login, etc.)
   - Checks breach databases, scans ports, discovers cloud storage
   - Mines JavaScript bundles for leaked API endpoints and internal hosts
   - Detects technologies, supply chain dependencies, and typosquat domains
   - Produces a complete EASM report with financial impact and compliance scoring

2. LIGHT TOUCH SCAN (10-20 seconds)
   - Single HTTP request — won't trigger WAF alerts
   - Still extracts SSL, headers, DNS, email security, technologies, and supply chain
   - Ideal for quick checks or sensitive environments

3. PASSIVE SCAN (5-10 seconds)
   - Zero traffic to the target domain — queries only third-party sources
   - DNS records, Certificate Transparency logs, WHOIS, Wayback Machine, breach databases
   - Perfect for pre-engagement reconnaissance or monitoring domains you don't own

WHAT GREYPING SCANS (16+ CAPABILITIES)

Website Security:
- SSL/TLS certificate grading (A-F), expiry warnings, cipher strength
- HTTP security headers audit (15+ headers, A-F grade)
- Cookie security analysis (Secure, HttpOnly, SameSite flags)
- Sensitive path detection (57 paths: .env, .git, /admin, /graphql, backup files)
- Secret & credential detection (AWS keys, API tokens, database URLs, private keys)
- Indicators of Compromise (cryptominers, hidden iframes, credential harvesting)

Network & Infrastructure:
- Port scanning (detect exposed databases, RDP, admin panels)
- Cloud storage discovery (S3 buckets, Azure Blob, Google Cloud Storage, Firebase)
- Technology fingerprinting (CMS, frameworks, CDNs, analytics — 60+ signatures)
- Supply chain analysis (third-party scripts, SRI compliance, vulnerable libraries)
- WAF/firewall detection

Email Security:
- SPF record analysis with full include-tree resolution
- DMARC policy validation
- DKIM selector checking
- MTA-STS and BIMI assessment
- Email service enumeration (which providers send on your behalf)

Passive Intelligence (zero traffic to target):
- DNS record enumeration (A, AAAA, MX, NS, TXT, CAA, SOA, SRV + DNSSEC)
- Certificate Transparency log search — discovers all subdomains ever issued certificates
- WHOIS/RDAP registration details
- Wayback Machine historical snapshots
- Breach database checking (Have I Been Pwned)

Brand Protection:
- Typosquatting detection — finds registered lookalike domains (TLD swaps, character omissions, homoglyphs)
- Privacy compliance scoring (privacy policy, cookie consent, GDPR/CCPA indicators)

THE EASM REPORT (THE CORE DELIVERABLE)

Every scan produces a business-grade EASM report containing:

1. OVERALL GRADE (A-F)
   - Single letter grade combining SSL, headers, email security, and privacy scores
   - Component breakdown: SSL: A, Headers: F, Email: C, Privacy: D → Overall: B

2. EXECUTIVE SUMMARY
   - 2-4 sentence plain-English narrative of the organisation's external risk posture
   - Top 3 strengths and top 3 concerns
   - Actionable recommendations

3. FINANCIAL IMPACT (FAIR Risk Quantification)
   - Estimated single-incident cost and annualised loss in dollars/euros
   - Based on the FAIR (Factor Analysis of Information Risk) framework
   - Scaled by company size (micro/small/medium/large/enterprise) — can be set explicitly or auto-inferred from scan signals
   - Adjusted for breach history, data sensitivity, credential exposure, and cloud database exposure
   - Benchmarked against IBM Cost of a Data Breach 2024 report

4. RANSOMWARE SUSCEPTIBILITY INDEX (0-100)
   - Score based on: exposed admin panels, weak email auth, missing WAF, unpatched vulnerabilities, exposed secrets
   - Tier: Low (0-24), Medium (25-49), High (50-74), Critical (75+)
   - Lists both risk factors and active mitigations

5. COMPLIANCE POSTURE
   - PCI-DSS 4.0: Tests 10 controls with pass/fail per control
   - ISO 27001: Tests 8 controls
   - GDPR: Tests 3 controls (Art.32, Art.33, Art.34)
   - Each finding is auto-tagged to relevant compliance frameworks
   - Readiness score per framework (0-100%)

6. PRIORITIZED FINDINGS (typically 30-50 per scan)
   - Each finding includes:
     * Severity: critical / high / medium / low / info
     * Classification: confirmed issue, platform behavior, informational, or likely false positive
     * Ownership: customer responsibility, platform-managed, third-party, or not actionable
     * Plain-English "why it matters" explanation
     * Business impact statement
     * Specific remediation action
     * Compliance framework tags

7. ATTACK PATH ANALYSIS
   - Connects individual findings into multi-step exploit chains
   - Example: "Exposed .env file + database credentials = direct data breach path"
   - Shows likelihood, impact, and remediation for each chain
